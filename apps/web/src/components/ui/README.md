# Componentes de UI

Componentes base del sistema de diseño (botón, input, card, dialog, etc.),
siguiendo el patrón de shadcn/ui: se copian al proyecto (no son una
dependencia de node_modules) para poder ajustarlos libremente al estilo
minimalista de EduApp. Generar con `npx shadcn-ui@latest add <componente>`.
